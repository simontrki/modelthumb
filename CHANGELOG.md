# Changelog

## 0.2.0-alpha – 2026-11-02

First public alpha release.

- Thumbnails for STL, 3MF, STEP, IGES, BREP, OBJ, PLY, OFF, glTF/GLB
- 3MF: uses embedded slicer previews; multi-part (production extension) projects
- CPU software renderer with smooth shading, crease-preserving normals and outlines
- `embed`: store previews inside 3MF files
- `cache`: pre-fill the freedesktop thumbnail cache
- `install` / `uninstall` for the current user or system-wide
- AppImage for x86_64, glibc >= 2.17
